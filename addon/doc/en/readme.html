Comment Commander

Comment Commander makes working with comments in Microsoft Word and Excel fast with NVDA. Instead of hunting through the comments pane, you get a searchable list of every comment, and one keypress takes you to the place it belongs to.

In Excel, both kinds of annotation appear in the same list. Word tracked changes are supported in the same way.

Requirements

  • NVDA 2023.1 or later.
  • Microsoft Word or Microsoft Excel (desktop). Word 2016 and later are recommended; resolving comments and replying to them require Word 2013 or later. Excel comment threads require Excel 2019 or Microsoft 365; classic notes work in any version.

Commands

Default keyboard commands
CommandAction
NVDA+shift+;Open the list of comments.
NVDA+;Report the comment at the cursor, followed by the text it is attached to. Press twice to copy it to the clipboard.
NVDA+alt+;Move to the next comment.
NVDA+alt+shift+;Move to the previous comment.
NVDA+control+;Add a comment on the current selection, or on the active cell in Excel.
NVDA+control+shift+;Open the list of tracked changes. Word only.
UnassignedReport how many comments and tracked changes the document has.
UnassignedOpen the Comment Commander settings.

All commands can be changed in NVDA's Input Gestures dialog, under the Comment Commander category.

Note for non-US keyboard layouts

NVDA works out which physical key the semicolon is on from your active keyboard layout, but it keeps only the key itself and not any shift the layout needs to produce the character. Which key you actually press therefore depends on your layout:

Where the semicolon key lands
LayoutPhysical key
US, US InternationalThe semicolon key, as printed.
Belgian (period) and Belgian French AZERTYThe semicolon key, as printed.
Dutch (Netherlands)The comma key, because the semicolon sits on shift+comma there. NVDA+shift+; is therefore NVDA+shift+comma, which is the same thing you would press to type a semicolon anyway. NVDA+; is NVDA+comma.

All six commands stay distinct on each of these layouts, so nothing clashes. If your layout has no semicolon at all, or you simply prefer different keys, assign your own in Input Gestures; everything else works exactly the same.

The comments list

Press NVDA+shift+; in a Word document. The dialog opens with focus in the filter field, so the fastest route to any comment is: type a few words, press down arrow to move into the list, then Enter.

Enter on a comment closes the dialog and puts the Word cursor at the start of the text the comment is attached to, ready for you to read or edit.

What the list shows

Each row gives the number, author, comment text, the annotated text it refers to, the status, the number of replies, the page and the date. Replies appear directly under the comment they belong to and are labelled as replies, so a thread reads as a unit.

Below the list, a read-only Details field holds the complete text of the selected comment. Long comments are truncated in the list but never here, so tab to it and read with the arrow keys when a comment does not fit on one line.

Filtering and sorting

  • Filter — matches on comment text, annotated text and author. Multiple words all have to match, so anna typo finds Anna's comments mentioning a typo.
  • Author — restrict the list to one reviewer.
  • Sort by — document order (the default), author, date or status.
  • Show resolved — hide comments that have already been resolved.

Acting on comments

These buttons let you handle a review without ever entering the comments pane:

  • Reply — type a reply in a normal edit field and it is added to the thread.
  • Edit — change the text of an existing comment.
  • Resolve / Reopen — mark a thread as done, or bring it back.
  • Delete — remove a comment, with confirmation.
  • Copy and Copy all — put the selected comment, or everything currently listed, on the clipboard. Copy all respects the filter, so it is an easy way to produce a summary of one reviewer's remarks.

The list refreshes from Word after every change, so it always reflects the document.

Microsoft Excel

The same commands work in Excel. The list shows every annotation in the whole workbook, across all worksheets, with a Sheet and a Cell column; Enter activates that sheet and moves to the cell.

Two kinds of annotation

Excel has two, and both appear in the list, told apart by the Type column:

What each kind supports
NoteComment thread
What it isThe classic yellow sticky note.The modern comment, with replies.
AuthorYesYes

RepliesNoYes

The Kind combo box filters the list down to one of the two. The Reply button is unavailable while a note is selected, because a note has no thread to reply to; convert it to a comment in Excel first.

Adding a comment with NVDA+control+; creates a modern comment thread when Excel supports it, and falls back to a classic note when it does not.

Tracked changes

NVDA+control+shift+; opens the same kind of list for tracked changes, showing the type of change, the author, the affected text, the page and the date. Enter goes to the change; Accept and Reject apply it.

Settings

NVDA menu, Preferences, Settings, Comment Commander:

  • After moving to a comment, announce — nothing extra, the annotated text (the default), the comment, or both.
  • Select the annotated text when moving to a comment — off by default, which places the cursor at the start of the annotated text. Turning it on selects the whole annotated range instead. Useful for replacing the text outright, but remember that anything you type then overwrites the selection.
  • Show resolved comments in the list by default.
  • Report page numbers in the list — the page number is looked up for the row you are on rather than for the whole document at once, so this costs nothing noticeable even in a long document. Turn it off if you never use the Page column.
  • Ask for confirmation before deleting a comment.
  • Remember the filter text between sessions.

Where the commands work

All commands are inactive unless Microsoft Word or Microsoft Excel has the focus. Pressing one elsewhere reports "Not in a Microsoft Word or Excel document" and does nothing else, so the add-on can never act on a document sitting in the background while you are working in another application.

Word used as the editor for an Outlook message counts as Word, as long as a real document window is present. Opening the add-on's settings is the one command that works everywhere.

Known limitations

  • Resolving comments and replying require Word 2013 or later. In older versions those buttons are unavailable.
  • In a protected or read-only document, Word refuses changes. The add-on reports this rather than failing silently.
  • Editing the text of a comment replaces the whole body, including any formatting it had.
  • Excel does not expose whether a comment is resolved, so the add-on cannot show or change that. The Resolve button stays unavailable in Excel. Resolving still works normally inside Excel itself.
  • Excel notes cannot hold replies. That is how Excel works, not a limitation of the add-on.
  • Excel has no tracked changes comparable to Word's, so that command reports that it is a Word feature.
